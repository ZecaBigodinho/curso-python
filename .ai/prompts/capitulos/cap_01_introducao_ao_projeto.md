## Objetivo

Apresentar o escopo do Sistema Escolar, definir os requisitos funcionais do projeto, explicar a metodologia Project Based Learning, organizar as equipes de desenvolvimento e estabelecer o cronograma até o prazo final (20 de agosto).

## Contexto

Este é o **primeiro capítulo** do módulo Projeto Finalizador. Não existe capítulo anterior. Os alunos acabaram de concluir os módulos de Fundamentos, Interfaces Gráficas e Banco de Dados. Agora eles vão aplicar tudo em um sistema real.

## Competências a Desenvolver

- Levantamento de requisitos funcionais
- Planejamento de projeto de software
- Visão sistêmica (entender o todo antes das partes)
- Organização de equipes de desenvolvimento
- Diferença entre programar e desenvolver sistemas

## Resultado Esperado

Ao final deste capítulo, o aluno terá:
- Compreendido o escopo completo do Sistema Escolar
- Definido os requisitos funcionais (Login, Menu, Cadastro, CRUD, Banco)
- Formado sua equipe de desenvolvimento
- Definido o tema do projeto da equipe
- Compreendido o cronograma e os entregáveis

## Tópicos Obrigatórios

1. O que é um sistema de gestão escolar
2. Fluxo completo: Login → Menu → Cadastro → CRUD → SQLite → Nuvem → Entrega
3. Requisitos funcionais (lista detalhada do que o sistema fará)
4. Diferença entre programar isoladamente e desenvolver um sistema completo
5. Metodologia PBL: aprender construindo
6. Formação das equipes e escolha do projeto
7. Cronograma: o que será feito em cada aula até a entrega

## Regras Especiais deste Capítulo

- Este capítulo é predominantemente conceitual — menos código, mais planejamento
- Incluir um diagrama ASCII do fluxo completo do sistema
- Incluir tabela de requisitos funcionais
- A "Missão da Equipe" deve ser: definir o tema do projeto da equipe e listar os requisitos funcionais adaptados
- O "Desafio" deve ser: criar um fluxograma do sistema da equipe (em papel ou no computador)
