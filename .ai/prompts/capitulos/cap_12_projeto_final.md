## Tópicos Obrigatórios

1. Checklist final de funcionalidades obrigatórias:
   - [ ] Login funcional
   - [ ] Menu principal com navegação
   - [ ] Múltiplas janelas sem duplicação
   - [ ] Cadastro com validação
   - [ ] Consulta/busca funcional
   - [ ] Atualização de registros
   - [ ] Exclusão com confirmação
   - [ ] SQLite persistindo dados
   - [ ] Banco em nuvem sincronizando
   - [ ] Código documentado (docstrings)
   - [ ] README.md completo
   - [ ] requirements.txt atualizado
2. Roteiro de apresentação (5-10 minutos):
   - Introdução do projeto
   - Demonstração das funcionalidades
   - Explicação da arquitetura
   - Desafios enfrentados
   - Aprendizados
3. Como demonstrar o sistema ao professor:
   - Fluxo completo do login ao CRUD
   - Mostrar persistência (fechar e reabrir)
   - Mostrar sincronização com nuvem
4. Critérios de avaliação (transparentes para o aluno)
5. Autoavaliação da equipe:
   - O que funcionou bem na equipe?
   - O que foi mais difícil?
   - O que cada membro contribuiu?
6. Registro de aprendizados (reflexão individual)
7. Sugestões de melhorias futuras (o que fariam com mais tempo)
