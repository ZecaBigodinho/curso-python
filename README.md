## 📚 Conteúdo do Curso

O curso está dividido em **3 módulos progressivos**:

### 🐍 Módulo 01 — Fundamentos de Python
> Os alicerces da linguagem

- Variáveis, tipos de dados e operadores
- Estruturas condicionais e laços de repetição
- Funções, módulos e organização de código
- Coleções (listas, dicionários, tuplas, sets)
- Manipulação de strings e arquivos
- Tratamento de exceções
- Projeto Final de consolidação

### 🖥️ Módulo 02 — Interfaces Gráficas
> Criando janelas e aplicações visuais

- Tkinter Básico — janelas, widgets, botões e inputs
- Gerenciadores de layout (`pack`, `grid`, `place`)
- Eventos, interatividade e bindings
- CustomTkinter — interfaces modernas e estilizadas
- Projeto Prático com UI profissional

### 🗄️ Módulo 03 — Banco de Dados
> Persistência e integração de dados

- Introdução ao SQLite — criação de tabelas e consultas SQL
- Integração do banco de dados com a interface gráfica
- Variáveis de ambiente (`.env`) para proteção de credenciais
- **Projeto Final** — aplicação completa para certificação
