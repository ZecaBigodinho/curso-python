# 🧠 Central de Revisão Visual & Fixação Didática

> **Curso:** Python para Desktop  
> **Objetivo:** Material de apoio didático e altamente visual para alunos que buscam consolidar conceitos essenciais e tirar dúvidas com metáforas simples, fluxogramas e solução de erros comuns.

---

## 🎯 Como utilizar esta seção?

Esta central foi criada para ser seu **porto seguro** sempre que algum assunto parecer abstrato durante as aulas. Aqui nós trocamos a linguagem técnica por:

* 🏬 **Metáforas do Mundo Real** (comparações físicas com o cotidiano).
* 📊 **Fluxogramas Interativos em Mermaid.js** (desenho do caminho de execução do código).
* 🔍 **Comparativos em Grid Cards** (o que parece ser vs. o que realmente é).
* ⚠️ **Mapeamento Humanizado de Erros** (por que o código quebrou e como corrigir).
* 🧪 **Quizzes Interativos de Fixação** (com respostas expansíveis).
